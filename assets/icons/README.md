# 300 Icon Export Catalog

This is an **export-only** catalog. Android launchers control whether imported icon images can replace application icons, so 300 must describe this as launcher-dependent export/share—not universal or one-tap installation.

`manifest.json` is the release inventory for six families of 16 glyphs. `masters/300-icon-glyphs.svg` is the original bronze/obsidian master-board starter. Deterministic original SVG exports are available under `exports/`. They use the project's bronze/obsidian glyph treatment and remain launcher-dependent export/share assets; they must not be represented as universal one-tap launcher installation.
