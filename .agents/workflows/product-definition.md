# Workflow: Product Definition

## Objective
Define the core product promise, user personas, MVP boundary, engagement loops, and monetization strategy for 300.

## Leading Agent
`product-agent.md` (in coordination with `research-agent.md` and `reviewer-agent.md`)

## Execution Protocol

### Step 1: Clarify Core Value Proposition
1. Define the singular emotional payoff: "My phone feels like a different device now."
2. Establish the four pillars:
   - High-impact, dark, brutalist wallpapers
   - Live Glance home-screen widgets (Daily discipline quote & streak)
   - 300 Daily Discipline Challenge loop (< 1 min daily commitment)
   - Cohesive Spartan/Warrior thematic personalization

### Step 2: Establish User Personas
- **The Modern Warrior / Discipline Seeker**: Focus on fitness, mental grit, stoicism, daily habits, and minimizing phone addiction.
- **The Aesthetic Minimalist**: Appreciates dark mode, brutalist design, clean typography, and cinematic visual restraint.

### Step 3: Define MVP Boundaries
- What is IN MVP:
  - Curated initial pack of Spartan/Discipline wallpapers with full-screen preview & 1-tap apply.
  - Daily Spartan Discipline Challenge with streak counter and local completion storage.
  - 2 Glance Home-Screen Widgets: Minimal Quote Widget & Spartan Streak Widget.
  - Dark Theme core UI, fully functional offline.
  - Free vs. Premium entitlement structure (unlocking exclusive themes/wallpapers).
- What is OUT of MVP:
  - Live animated video wallpapers (saved for Phase 14).
  - Social feeds / community leaderboards (avoids server costs & distractions).
  - Heavy background audio/music recitations.

### Step 4: Publish Specification
- Update `.agents/specs/product-spec.md`.
- Review with `reviewer-agent.md`.
- Log approved scope in `.agents/states/product.md`.
